# Wytwarzanie przyrostowe metalowych struktur kratowych

Projekt realizowany w ramach konkursu organizowanego przez Politechnikę Śląską, poświęcony wytwarzaniu przyrostowemu cienkościennych metalowych struktur kratowych oraz analizie ich zachowania podczas oddziaływania temperatury.

## Tematyka projektu
- wytwarzanie przyrostowe struktur metalowych,
- cienkościenne struktury kratowe,
- zachowanie struktur pod wpływem oddziaływania termicznego.
