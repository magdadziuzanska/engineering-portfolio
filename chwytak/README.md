# Projekt chwytaka mechanicznego

Projekt wykonany w Autodesk Inventor w ramach pracy akademickiej.

## Zakres projektu
- modelowanie 3D elementów chwytaka,
- analiza kinematyczna mechanizmu,
- obliczenia wytrzymałościowe ramion i sworzni,
- dobór siłownika,
- przygotowanie rysunku złożeniowego.
